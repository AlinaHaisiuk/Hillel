# Express JWT Cookies Project

## Опис

Цей проект демонструє, як працювати з статичними файлами, cookies та JWT на сервері **Express**. Він включає такі функції:

- Збереження **тем** через cookies.
- Реєстрація та вхід користувачів з використанням **JWT** для авторизації.
- Захищений маршрут, доступний лише після перевірки токена.

## Технології

- Node.js
- Express.js
- Pug для шаблонів
- cookie-parser для роботи з cookies
- jsonwebtoken для роботи з JWT
